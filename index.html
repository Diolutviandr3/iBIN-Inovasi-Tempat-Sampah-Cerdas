Tentang iBIN

Inovasi Tempat Sampah Cerdas Terintegrasi IoT

iBIN (TECHNOLOGY-IoT BIN) adalah solusi inovatif untuk mengatasi masalah pengelolaan Municipal Solid Waste (MSW) di Indonesia dengan mengintegrasikan teknologi IoT dalam sistem tempat sampah pintar. Sistem ini dirancang untuk memilah berbagai jenis sampah (plastik, organik, kertas, dan logam) secara otomatis, memantau kapasitas wadah secara real-time, dan memfasilitasi daur ulang yang lebih efektif.

iBIN merupakan bagian dari upaya mewujudkan Sustainable Development Goals (SDGs) khususnya dalam hal pengelolaan sampah berkelanjutan dan penciptaan kota yang tangguh sesuai dengan poin ke-11, 12, dan 13 dari SDGs.

Fitur Utama

  • Sistem pemilahan otomatis menggunakan sensor cerdas dan mekanisme pintar
  • Monitoring real-time tingkat kepenuhan sampah melalui platform dashboard
  • Integrasi IoT dengan sensor Time of Flight dan mikrokontroler
  • Notifikasi otomatis kepada petugas ketika kontainer hampir penuh
  • Pengumpulan data analitik untuk optimasi proses pengelolaan sampah

Pemantauan Berbasis Web

Seluruh proses pada iBIN dapat dipantau melalui sistem pemantauan berbasis web yang terhubung langsung dengan perangkat IoT. Data dari sensor dikirimkan ke server menggunakan protokol komunikasi seperti MQTT atau HTTP sehingga informasi mengenai jenis sampah, tingkat kepenuhan wadah, serta status sistem dapat diperbarui secara real-time. Antarmuka web menampilkan data tersebut dalam bentuk grafik dan indikator status sehingga operator dapat memantau kinerja iBIN dari jarak jauh. Sistem ini juga mampu memberikan notifikasi ketika terjadi kondisi tertentu seperti wadah hampir penuh atau hambatan pada sistem pemilahan. Dengan demikian, pemantauan berbasis web meningkatkan keandalan operasional iBIN serta memastikan proses pengolahan sampah berjalan lebih efisien dan terkendali.
